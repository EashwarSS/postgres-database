1. Open pgAdmin
2. PostgreSQL 17 < Databases < Right click < Create < name as "new DB"
3. Click on new DB, click on query tool, copy .sql script and run
4. Open new DB < Schemas < Tables (Refresh) < you can see new table is created
5. Right click on new table < import < add the .csv file
6. new table < right click < view/edit data < all rows
7. All csv data imported to tables
